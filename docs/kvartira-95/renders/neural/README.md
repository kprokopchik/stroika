# Фотореалистичные визуализации варианта 1

15 интерьерных ракурсов доработаны нейросетью по исходным Blender-рендерам из соседней папки. Файлы JPG, 3D-модель, виды сверху и общие изометрии сохранены для сверки планировки.

Сохранены исходные ракурсы и расположение крупной мебели; уточнены материалы, свет, фурнитура и геометрия условных предметов. В санузле у входа показаны две машины в колонне. Внешний вид отделки, мелкие предметы и вид из окон — визуальная концепция, а не обмеры или спецификация оборудования.

Сайт показывает эти PNG в варианте 1 и на страницах его комнат. Исходные ракурсы доступны в раскрываемом блоке. Варианты 2/3 используют свои прежние изображения. После изменения планировки или исходного ракурса соответствующую нейровизуализацию следует обновить; исходные хеши записаны в manifest.json.
