PDF для печати · A4

Номера слева задают безопасную последовательность. Код шага сохраняет номер раздела сметы: например, закрытие стен 1.03 идёт после испытаний 2.06, мокрая отделка 5.01…5.03 — перед деревянным полом 4.01…4.03, а фартук 5.04 — после кухни 7.02. Независимые работы можно совмещать после выполнения зависимостей.

Встроенные шкафы, кухня, скамья и ограждение душа оплачиваются в расчётном сценарии 50/50: аванс на шаге 7.01, остаток при монтаже. Полный заказ учитывается один раз. Доставка и резерв распределены из прежних общих сумм; стоимость квартиры не увеличена.
