Квартира 95,7 м²

Планировка застройщика: спальня 19,5 м², комната 13,6 м², гостиная 17,6 м², кухня 19,6 м², прихожая 11,8 м², коридор 6,0 м² и два санузла. Мебель застройщика убрана, предложены три варианта: вторая детская сделана из гостиной, кухня-гостиная — в кухне 19,6 м².

95,7 м² по сумме помещений93,7 м² по данным застройщикапотолок 2,7 мбез отделкиразмеры сняты с плана, ±5 см
