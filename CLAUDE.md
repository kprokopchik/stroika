# Правила репозитория «Стройка»

- Сайт статический: `python3 build.py` пересобирает `docs/` целиком из `projects/*`, `tools/` и `site_assets/`. Папку `docs/` коммитим вместе с исходниками: GitHub Pages раздаёт её из ветки `main`, папка `/docs`.
- GitHub Actions не используем (у владельца нет бесплатных минут). Никаких workflow в `.github/`.
- Сборка сайта — только стандартная библиотека Python 3.10+. 3D (`tools/scene3d.py`) — отдельно, через `bpy==4.2.0` на Python 3.11, по желанию.
- Координаты плана в сантиметрах: x вправо, y вниз. Источник размеров — `plan.jpg` объекта, масштаб записан в описании объекта.
- Все тексты на сайте по-русски, простыми фразами. Размеры в см, площади в м² с запятой: 13,6 м².
- Ссылки на сайте только относительные: сайт живёт в подпапке `kprokopchik.github.io/stroika/`.
- Навигация — дерево: объект → вариант → план, 3D, комнаты, разделы → страницы раздела. На каждой странице хлебные крошки.
- Планы на страницах — в просмотрщике с зумом (`site_assets/app.js`). Проверяем на телефоне: щипок, перетаскивание, «На весь экран».
- Репозиторий публичный: никаких личных данных владельца (имя, телефон, почта, точный адрес) в файлах и на страницах.
- Инженерные разделы (электрика, вода, слаботочка) — в `projects/<объект>/eng.py`, функция `build(n)`; символы — `tools/eng_svg.py`. Нет данных для варианта — раздел остаётся черновиком.
- Общий код меняем обратно совместимо. Перед пушем в `main`: fetch, merge, `python3 build.py`, push. Конфликты в `docs/` — пересборкой, не руками.
- Правила владельца по планировкам: холодильник и духовку не прячем в нишу; посудомойка считается рабочей поверхностью 60 см; в прихожей не делаем длинных узких коридоров.
- Кровать — вне прямой видимости от двери. Унитаз не должен быть виден из прихожей и кухни-гостиной.
- Выключатели — со стороны ручки, с учётом наличника 7–10 см: между проёмом и мебелью сбоку оставляем 15–20 см.
- В детских не ставим скамьи с ящиками: вместо них стеллажи и игровые стены без потери пола — шведская стенка или скалодром вплотную к стене, кровать-домик. Домик за шведской стенкой в метре от стены — слишком тесно. В разных детских можно показывать разные решения, владелец выберет.
- У каждой кровати — тумбочка или полка и розетка с USB в одном месте, в зоне досягаемости лёжа.
- Такие тонкости пишем в блок «На что обратить внимание»: `TIPS` в `content.py` (общие и по комнатам для каждого варианта).
