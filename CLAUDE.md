# Правила репозитория «Стройка»

- Сайт статический: `python3 build.py` пересобирает `docs/` целиком из `projects/*`, `tools/` и `site_assets/`. Папку `docs/` коммитим вместе с исходниками: GitHub Pages раздаёт её из ветки `main`, папка `/docs`.
- GitHub Actions не используем (у владельца нет бесплатных минут). Никаких workflow в `.github/`.
- Сборка сайта — только стандартная библиотека Python 3.10+. 3D (`tools/scene3d.py`) — отдельно, через `bpy==4.2.0` на Python 3.11, по желанию.
- Координаты плана в сантиметрах: x вправо, y вниз. Источник размеров — `plan.jpg` объекта, масштаб записан в описании объекта.
- Все тексты на сайте по-русски, простыми фразами. Размеры в см, площади в м² с запятой: 13,6 м².
- Ссылки на сайте только относительные: сайт живёт в подпапке `kprokopchik.github.io/stroika/`.
- Навигация — дерево: объект → вариант → план, 3D, комнаты, разделы → страницы раздела. На каждой странице хлебные крошки.
- Планы на страницах — в просмотрщике с зумом (`site_assets/app.js`). Проверяем на телефоне: щипок, перетаскивание, «На весь экран».
- Репозиторий публичный: никаких личных данных владельца (имя, телефон, почта, точный адрес) в файлах и на страницах.
